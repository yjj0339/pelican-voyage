# 鹈鹕骑行之旅 - Pelican Voyage

🚴‍♂️ 一只快乐的鹈鹕骑着自行车穿越美丽的风景

## 特性

- 纯 Canvas 2D 渲染，零依赖
- 双骨 IK 腿部动画，真实踏板联动
- 三层视差背景（远山、树木、草地）
- 平滑的骑行动画与垂直抖动

## 技术实现

- **IK 求解器**：双骨反向运动学，腿部跟随踏板旋转
- **视差滚动**：不同速度的背景层营造景深
- **程序化绘制**：太阳、云朵、树木全部代码生成

## 本地预览

直接在浏览器中打开 `index.html` 即可。
